# Command Examples

This file collects copy-paste-ready snippets for every CLI command. Mix and match them to build your own workflows, and refer back to `README.md` for context plus `docs/TROUBLESHOOTING.md` if something goes sideways.

## Launch Agents

### Basic plan file

```bash
bun run cloud-agent.tsx launch --plan plan/refactors/cleanup.md
```

### Disable automatic PR creation

```bash
bun run cloud-agent.tsx launch \
  --plan plan/chore/update-deps.md \
  --no-auto-pr
```

### Override repo, ref, branch, and model

```bash
bun run cloud-agent.tsx launch \
  --plan plan/reports/generate.md \
  --repo https://github.com/acme/payments \
  --ref release/2025.05 \
  --branch hotfix/payments-rollup \
  --model gpt-5.1-codex
```

### Launch from heredoc

```bash
bun run cloud-agent.tsx launch --plan - <<'EOF'
refactor(api): add webhook retries

- document retry policy
- send metrics to dashboard
EOF
```

### Launch with inline JSON payload

```bash
cat <<'JSON' > /tmp/prompt.json
{
  "prompt": { "text": "feat(agent): add async git detection" },
  "source": { "repository": "https://github.com/acme/agents", "ref": "main" },
  "target": { "autoCreatePr": true },
  "model": "gpt-5.1-codex"
}
JSON

curl https://api.cursor.com/v0/agents \
  -H "Authorization: Basic $(printf '%s:' "$CURSOR_API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d @/tmp/prompt.json
```

## Monitor Agents

### Non-interactive list (script-friendly)

```bash
bun run cloud-agent.tsx list --non-interactive
```

### Filter for the newest agent ID

```bash
LATEST_ID=$(bun run cloud-agent.tsx list --non-interactive | head -n 1 | awk '{print $1}')
echo "Latest agent: ${LATEST_ID}"
```

### Watch until completion with custom interval

```bash
bun run cloud-agent.tsx watch "$LATEST_ID" --interval 5000 --verbose
```

### Check status and branch logic on success

```bash
AGENT_ID=bc_abc123
if bun run cloud-agent.tsx status "$AGENT_ID" --non-interactive | grep -q FINISHED; then
  bun run cloud-agent.tsx open "$AGENT_ID" --pr
else
  echo "Agent still running or failed."
fi
```

## Collaborate With Agents

### Send a follow-up instruction

```bash
bun run cloud-agent.tsx followup "$AGENT_ID" "Please also update docs/EXAMPLES.md."
```

### Send follow-up from file

```bash
bun run cloud-agent.tsx followup "$AGENT_ID" @followup/add-tests.md
```

### Review conversation history

```bash
bun run cloud-agent.tsx conversation "$AGENT_ID" --non-interactive
```

## Manage Agent Lifecycle

### Open agent or PR URLs

```bash
bun run cloud-agent.tsx open "$AGENT_ID"
bun run cloud-agent.tsx open "$AGENT_ID" --pr
```

### Cancel or delete

```bash
bun run cloud-agent.tsx cancel "$AGENT_ID"
bun run cloud-agent.tsx delete "$AGENT_ID" --force
```

### Batch delete with filters

```bash
# Preview first
bun run cloud-agent.tsx batch-delete --status FINISHED --dry-run

# Delete stale agents for a specific repo
bun run cloud-agent.tsx batch-delete \
  --status FINISHED \
  --repo https://github.com/acme/agents \
  --limit 25 \
  --force
```

## Automation Recipes

### Chain launch + watch + follow-up

```bash
AGENT_ID=$(bun run cloud-agent.tsx launch --plan plan/refactor.md)
bun run cloud-agent.tsx watch "$AGENT_ID" --verbose && \
  bun run cloud-agent.tsx followup "$AGENT_ID" "Ship a quick summary."
```

### Daily cleanup cron job

```bash
0 9 * * * cd /path/to/repo && \
  bun run cloud-agent.tsx batch-delete --status FINISHED --force
```

### CI sanity check

```bash
set -euo pipefail
AGENT_ID=$(bun run cloud-agent.tsx launch --plan plan/ci/pre-release.md --model gpt-5.1-codex)
bun run cloud-agent.tsx watch "$AGENT_ID" --interval 10000 --verbose
bun run cloud-agent.tsx status "$AGENT_ID" --non-interactive | tee agent-status.log
```

## Combine CLI with Direct API Calls

- Use the CLI to prototype prompts quickly.
- Capture the autogenerated plan with `--plan -` and pipe it into your own API script once you need more control.
